# Officer Dashboard UI Update

Applied the latest officer-mode feedback:

- Recent Field Screenings now shows only **one** recent screening card; **View All** still opens the complete results list.
- Added a dedicated **LIVE SAMPLE CAMERA** action in Rapid Field Actions.
- Live Sample Camera opens the existing native camera viewfinder for capturing sample/packaging evidence.
- Capturing an image closes the camera panel and returns to the dashboard.

The rest of the existing officer workflow and navigation are unchanged.
